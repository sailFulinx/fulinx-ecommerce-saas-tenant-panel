# FulinxCms

FulinxCms is a content management system based on Vue3, Element Plus, and TypeScript, providing basic article management, category management, tag management, file management, and other functions. It also provides a backend UI component library based on Element Plus, making it easy for developers to quickly build their own management systems.

## Project Features

- Developed using Vue3 Composition API
- Uses Element Plus as the UI component library
- Uses TypeScript for code checking
- Uses Pinia for state management
- Uses vite for development and building
- Uses ESLint and Prettier for code checking and formatting
- Uses Cypress for E2E testing

## Project Structure

- `src` - source code directory
  - `api` - API interface directory
  - `components` - component directory
  - `data` - data directory
  - `stores` - Pinia state management directory
  - `types` - type declaration directory
  - `utils` - utility function directory
  - `views` - view directory
- `public` - public resources directory
- `dist` - directory for generated files in production environment

## Running the Project

1. Install dependencies

   npm install

2. Run development environment

   npm run dev

3. Build production environment

   npm run build

4. Preview production environment

   npm run preview

5. Run E2E tests

   npm run test:e2e
